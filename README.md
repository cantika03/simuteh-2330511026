## Deskripsi Proyek
Proyek ini merupakan tugas Evaluasi Praktikum Computer Vision SIMUTEH. Praktikum membahas pengolahan citra digital menggunakan Python dan OpenCV, mulai dari pengenalan lingkungan pemrograman, analisis citra warna, histogram, penapisan citra, hingga praproses citra.

## Tujuan
1. Memahami dasar pengolahan citra digital.
2. Menganalisis karakteristik warna dan histogram citra.
3. Menguji metode penapisan untuk mengurangi noise.
4. Menerapkan praproses citra dan membandingkan hasilnya.

## Struktur Folder
- `data/sintetis/` — Dataset sintetis dan label citra.
- `notebook/` — Notebook praktikum Computer Vision.
- `src/` — Kode sumber Python.
- `hasil/` — Hasil pengujian dan analisis.
- `laporan/` — Laporan dan presentasi praktikum.
- `requirements.txt` — Daftar pustaka Python yang dibutuhkan.

## Teknologi yang Digunakan
- Python
- OpenCV
- NumPy
- Matplotlib
- scikit-image
- Pandas
- Pillow

## Cara Menjalankan
1. Unduh atau salin repository ini.
2. Instal pustaka yang diperlukan dengan perintah:

   `pip install -r requirements.txt`

3. Buka notebook praktikum menggunakan Google Colab atau Jupyter Notebook.
4. Sesuaikan lokasi dataset dengan struktur folder proyek.
5. Jalankan sel notebook secara berurutan.

## Dataset
Dataset yang digunakan merupakan dataset sintetis untuk keperluan praktikum. Dataset disimpan dalam folder `data/sintetis/`, yang mencakup citra, citra bersih, mask daun, mask bercak, serta file label.

## Catatan
Hasil pengujian digunakan untuk mempelajari penerapan metode pengolahan citra digital pada dataset sintetis.
